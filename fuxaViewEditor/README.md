# FUXA View Editor

新版 FUXA 配置編輯工具，使用 React、TypeScript、Ant Design 與 Vite。階段 5 所列的 View、Tag、ModbusTCP、圖示庫與樓層管理切片已接入工作台；舊版原生工具仍保留在上一層目錄，供比對與回退使用。

## 目前功能

- 在瀏覽器本機開啟 FUXA JSON，不上傳配置。
- 驗證配置需包含 `devices` 與 `hmi.views`。
- 顯示 View 清單及選取 View 的基本資訊。
- 新增空白 View、重新命名及刪除 View；刪除時會清理起始頁與導覽引用，並保留至少一個 View。
- 在選取的 View 批次加入既有 Tag，支援搜尋、全選搜尋結果，並沿用 Tag 已設定的樓層。
- 新增、修改、刪除 ModbusTCP 設備；管理 addressCount 補位及整台設備 Tag 位址 ±1，越界時整批取消。
- 管理 Tag 樓層，支援搜尋、多選、全選可見項目、批次套用及依樓層分組／平面清單切換。
- 管理圖示庫中的一般圖示與正常／告警圖示組；支援 PNG、JPEG、GIF 原始資料保存、預覽，以及阻止刪除仍被 View 使用的圖示。
- 設定所有 View 共用的樓層 Group 底框底色、透明度、邊框、圓角及內距。
- 編輯可管理元件的標籤、Tag 綁定、圖形（矩形、圓柱、一般圖示或正常／告警圖示組）、狀態配色及圖示組狀態反轉，或移除元件。
- 調整每個 View 的 Grid 排版設定。
- 預覽目前 View 與編輯後的佈局；預覽為唯讀，排版超出畫布時會提示，並移除危險 SVG 元素、事件處理器與外部資源連結。可切換即時預覽或手動更新；即時預覽會在編輯停止約 180 毫秒後重繪。
- Undo/Redo 編輯，載入新檔與成功匯出後清空編輯歷程。
- 未匯出修改時，重新載入檔案及離開頁面會提示確認。
- 匯出前套用 SVG 變更並驗證輸出；無修改時保留原始配置文字另存。
- 保留原始配置物件與輸入文字，未修改時可依原始位元組另存。
- 修改配置時的 JSON 序列化工具會保留來源換行格式與結尾換行策略。

## 使用方式

需要 Node.js 與 Yarn。從此目錄安裝依賴並啟動開發伺服器：

```powershell
yarn install
yarn dev
```

Vite 會顯示本機網址；在瀏覽器開啟後，使用「開啟 JSON」選擇配置。編輯及匯出都在瀏覽器本機完成，配置不會上傳。匯出會下載新 JSON，不會覆寫來源檔。

正式建置及本機預覽：

```powershell
yarn build
yarn preview
```

建置輸出位於 `dist/`。目前應透過 Vite 或其他靜態 HTTP 伺服器開啟；尚未驗證直接以 `file://` 開啟或單檔 HTML 部署。

## 範圍與注意事項

- 階段 5 列出的管理功能已可在新版工作台使用；其他設備通訊類型及進階 Tag 維護尚未遷移。
- 編輯歷程使用 reducer 管理並支援 Undo/Redo，但完整應用 Store 尚未依設計文件的完整架構拆分。
- 新舊版本輸出尚未完成黃金檔逐位元組比對；產生的配置仍需在目標 FUXA 環境驗證。
- E2E、完整鍵盤／無障礙檢查，以及離線網路請求驗證仍待補齊。
- SVG 預覽會複製並套用目前 View／模型、建立預覽 SVG 並清理危險內容；大型配置或頻繁編輯時可能增加主執行緒工作量。即時模式採短暫 debounce；若仍覺得操作卡頓，可關閉即時更新並用「更新預覽」手動刷新。
- 未修改的配置會沿用原始 JSON 文字；有修改時會套用變更、驗證並另存為新檔。

## 開發

使用 Yarn（專案已提交 `yarn.lock`）。上述開發指令需在 `fuxaViewEditor/` 目錄執行。

## 驗證與建置

```powershell
yarn lint
yarn test
yarn typecheck
yarn build
```

Vite 使用相對資產路徑；建置目前會顯示 JavaScript chunk 大於 500 kB 的提醒，不影響建置成功。
